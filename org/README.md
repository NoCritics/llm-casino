# /org — Deliberative state

Subdirectories appear as agents start writing:
- okrs/, strategy/, decisions/, math/, marketing/, finance/, risk/
- standup/YYYY-MM-DD/{role}.md — async standup notes
- notebooks/{role}/ — private reflection memory
